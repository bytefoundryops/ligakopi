💵 Biaya Pendaftaran

2

👤 Satu Peserta, Satu Tim

Setiap peserta hanya diperbolehkan mendaftarkan satu tim FPL.

🏆 Wajib Bergabung di League

Setiap peserta wajib mengikuti Classic League (Coffee & Juice League) dan Head-to-Head League.

Catatan: Head-to-Head League saat ini sudah ditutup. Peserta baru yang belum bergabung tidak dapat masuk ke league tersebut.

🔄 Penalti Transfer

Setiap aktivitas transfer yang melebihi jumlah Free Transfer (FT) yang tersedia akan dikenakan penalti -4 poin per transfer, sesuai ketentuan resmi FPL.

🔒 Admin Mode — perubahan di sini memengaruhi data yang dilihat semua manager

Update data FPL

Pilih game week yang mau di-update, lalu klik tombol di bawah. Aplikasi akan mengambil data terbaru dari API resmi liga kamu dan menyimpannya sebagai GW yang kamu pilih.

Untuk refresh skor GW yang sedang berjalan, biarkan pilihan default. Untuk maju ke game week baru, ubah dropdown ini ke nomor GW berikutnya sebelum klik tombol — ini keputusan manual, tidak akan pernah terjadi otomatis.
Auto-refresh hanya me-refresh GW yang sedang aktif (tidak pernah maju sendiri ke GW baru) dan hanya berjalan selagi tab/app ini terbuka di browser — bukan scheduler server 24 jam.
Masukkan URL Cloudflare Worker kamu sendiri (kalau ada) diakhiri dengan ?url= — relay ini akan dicoba PALING PERTAMA sebelum proxy publik. Minta Claude membuatkan kode Worker-nya kalau belum punya.
🔒 Admin Mode — fallback manual kalau update otomatis gagal

Tempel JSON manual

🔒 Admin Mode — input poin per klub secara manual

Input manual per klub

Isi poin, pengurangan (hit transfer), poin Captain, dan poin Bench tiap klub untuk satu game week. Captain & Bench dipakai sebagai tiebreaker kalau ada total poin yang sama.

🔒 Admin Mode — kelola nama manager tiap tim

Nama manager per tim

Satu kata nama manager untuk setiap tim, ditampilkan di bawah nama tim pada Klasemen. Diambil otomatis dari nama tim — ubah sesuai nama manager sebenarnya bila perlu.

🔒 Admin Mode — cek kelengkapan & konsistensi data

Laporan Validasi Data

Pengecekan otomatis untuk membantu memastikan data liga lengkap dan konsisten.

💾 Backup & Restore

Data liga tersimpan di sistem penyimpanan bawaan Claude (bukan database yang bisa kamu akses langsung). Untuk jaga-jaga, unduh salinan datanya secara berkala sebagai file JSON.

Untuk memulihkan data dari backup: tempel isi file JSON di kotak bawah ini, lalu klik "Pulihkan". Ini akan menimpa semua data yang ada saat ini — pastikan file backup-nya benar.
🔒 Admin Mode — kelola data Head to Head (liga 807173)

Update Matches
