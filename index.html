🔒 Admin Mode — perubahan di sini memengaruhi data yang dilihat semua manager

Update data FPL

Pilih game week yang mau di-update, lalu klik tombol di bawah. Aplikasi akan mengambil data terbaru dari API resmi liga kamu dan menyimpannya sebagai GW yang kamu pilih.

Untuk refresh skor GW yang sedang berjalan, biarkan pilihan default. Untuk maju ke game week baru, ubah dropdown ini ke nomor GW berikutnya sebelum klik tombol — ini keputusan manual, tidak akan pernah terjadi otomatis.
Auto-refresh hanya me-refresh GW yang sedang aktif (tidak pernah maju sendiri ke GW baru), dan sekarang juga mencakup Head to Head Matches & Standings secara otomatis — jadi kamu tidak perlu lagi bolak-balik klik manual di tab Head to Head. Hanya berjalan selagi tab/app ini terbuka di browser — bukan scheduler server 24 jam.
Masukkan URL Cloudflare Worker kamu sendiri (kalau ada) diakhiri dengan ?url= — relay ini akan dicoba PALING PERTAMA sebelum proxy publik. Minta Claude membuatkan kode Worker-nya kalau belum punya.
🔒 Admin Mode — kelola nama manager tiap tim

Nama manager per tim

Satu kata nama manager untuk setiap tim, ditampilkan di bawah nama tim pada Klasemen. Diambil otomatis dari nama tim — ubah sesuai nama manager sebenarnya bila perlu.

🔒 Admin Mode — cadangkan & pulihkan data liga

💾 Backup & Restore

Data liga tersimpan di sistem penyimpanan bawaan Claude (bukan database yang bisa kamu akses langsung). Untuk jaga-jaga, unduh salinan datanya secara berkala sebagai file JSON.

Untuk memulihkan data dari backup: tempel isi file JSON di kotak bawah ini, lalu klik "Pulihkan". Ini akan menimpa semua data yang ada saat ini — pastikan file backup-nya benar.
🔒 Admin Mode — kelola data Head to Head (liga 807173)

Update Matches

Pilih game week yang mau di-update, lalu ambil data pertandingan H2H dari liga H2H.

Cara manual (kalau update otomatis gagal)
Buka fantasy.premierleague.com/api/leagues-h2h-matches/league/807173/?page=1&event=GW (ganti GW dengan nomor game week yang dipilih di atas), salin semua teksnya, lalu tempel di bawah.

Update Standings

Ambil klasemen H2H dari liga H2H.

Cara manual (kalau update otomatis gagal)
Buka fantasy.premierleague.com/api/leagues-h2h/807173/standings/, salin semua teksnya, lalu tempel di bawah.
🔒 Admin Mode — tandai siapa sudah/belum bayar traktir kopi

☕ Kelola Utang Kopi

Tim yang kalah tiap Game Week wajib mentraktir tim juara. Tandai di sini kalau traktirannya sudah lunas.

🔒 Admin Mode — Verifikasi data tersimpan vs data resmi FPL

✅ Verifikasi vs FPL Resmi

Ambil riwayat poin resmi langsung dari FPL untuk semua tim (pakai ID entry masing-masing), lalu otomatis perbaiki semua selisih yang ditemukan mengikuti data resmi — satu klik saja. Kalau ada yang perlu dibatalkan, tersedia di tab "Undo".

🔒 Admin Mode — ID Entry FPL setiap Tim

🔒 ID Entry Tim

Setiap tim FPL punya ID entry permanen (tidak berubah walau nama tim diganti). Ini kunci utama yang dipakai aplikasi untuk mencocokkan data — termasuk mengambil riwayat poin resmi GW1–GW38 langsung dari FPL (endpoint /api/entry/{ID}/history/, event 1=GW1, event 2=GW2, dst — otomatis mengikuti nomor GW-nya).

Liga Ngopi · data tersimpan otomatis · sumber resmi: fantasy.premierleague.com/leagues/803630
